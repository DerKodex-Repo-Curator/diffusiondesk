## Features

- Modern glassmorphism UI
- Local-first architecture
- Direct ComfyUI integration
- Text2Image
- Image2Image
- Inpaint
- Inpaint Sketch
- Generation history
- Checkpoint selector
- Dark / Light mode
- Local proxy with CORS handling
- Configurable API endpoint
- Responsive design
